# github-cn-guide

一个技能，专门陪不读英文界面的人在 GitHub 网页上干活：建仓库、传文件、改文件、看懂每个按钮。

## 它解决什么

GitHub 网页没有中文界面，浏览器翻译又会把 `main` 翻成「主要内容」、把 `No license` 翻成「无驾照」。这个技能把建仓和上传的每一步都写成"英文原文 + 中文意思 + 在屏幕哪个位置"，并且规定了一条节奏：**一次只给一个动作**，做完一步核对一步。

## 什么时候触发

- 要建仓库、上传文件、修改仓库里的文件
- 看不懂 GitHub 某个页面，要逐条翻译
- 卡住了、按钮点不动、传完了不知道对不对

## 里面有什么

`SKILL.md` 一份，含建仓六字段对照表、网页上传四步与三层核对、改删文件方法、术语对照表、两条浏览器翻译坑，以及明确列出"不要碰的东西"（`Create project` 不是仓库、`Copilot Upgrade` 是付费入口、镜像站会偷账号）。

## 怎么装

- **Claude Code**：把整个文件夹复制到 `~/.claude/skills/github-cn-guide/`，重启会话
- **Codex / Cursor 等**：把 `SKILL.md` 全文粘进 `AGENTS.md`、`.cursorrules` 或系统提示词
- **只想用一次**：把 `SKILL.md` 拖进对话当参考文档
